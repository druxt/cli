# create-druxt

> Create a [Druxt](https://druxtjs.org) site.

```bash
npm create druxt@latest my-site
```

This runs `drx init my-site` from [`@druxt/cli`](https://www.npmjs.com/package/@druxt/cli), with every argument passed through. Creating a site is all it does. The options are in the [repository README](https://github.com/druxt/cli#readme).
